# Bug checklist

For the verifier. Each line is a yes / no question about the bug as written.

- Can someone else follow the reproduction, with the actual and expected values?
- Is the cause hypothesis a hypothesis, not a prescribed fix?
- Is every criterion about the fixed behaviour, and can a test that fails on the defect and
  passes on the fix prove each one?
- If nothing is wrong, is the ticket dropped with the evidence, rather than "fixed"?
- Is `repo` the one repo the fix belongs to?
- Is anything left from the template: a guidance line, "replace this line", the sample `verify`?
