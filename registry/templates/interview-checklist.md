# Interview checklist

For the verifier. Each line is a yes / no question about the interview as recorded. The lint has
already checked the shape: every question has options, a guess and an answer, the restatement
has its six lines, and the owner's "yes" has a date. These need judgement.

## The questions

- Is each question a decision only the owner can make, not a fact the agent could have looked up
  in the code, the docs or the sources?
- Does each question ask one thing, with options a reader can tell apart?
- Does each guess give a real reason, from something the agent read?
- Where an answer sounded like best practice ("scalable", "the standard way"), did the agent ask
  what the owner would want if they didn't have to justify it?
- Did the confidence rise as the answers came in? Where it didn't for three questions, did the
  agent stop and say so?

## The restatement

- Does each of the six lines use the owner's words, and match the answers above it?
- Does "Not included" name the things a reader would otherwise expect to be built?
- Is the "yes" an explicit yes to this restatement, not "sounds good" or "whatever you think"?
- Does the brief beside it say the same thing: the outcome, the people, the success measures,
  the limits and the no-gos?
- Is anything left from the template: a guidance line, a placeholder, the sample id?
