# Design questions checklist

For you and the architect, before you approve the list.

## The questions

- Does each question name a choice the design must make, that current sources can inform?
- Is each one answerable without your private code (the architect reads that himself)?
- Is the list complete enough that Arlo's run 1 won't meet a big open choice?

## The stack summary

- Does it say what the research needs (language, framework and versions, database, deployment)?
- Does it hold nothing you wouldn't show a web page (no hostnames, keys, customer names)?
