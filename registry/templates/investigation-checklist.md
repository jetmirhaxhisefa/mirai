# Investigation checklist

For the verifier. Each line is a yes / no question about the investigation as written.

- Does it ask one question, and name the decision that waits on the answer?
- Does each criterion say what the finding must state, so a reader can tell the question is
  answered?
- Is it free of code work? A change to the code is a story of its own, after the finding.
- Do the sources give the run somewhere to start?
- Is `repo` the one repo the question is about?
- Is anything left from the template: a guidance line, "replace this line", the sample `verify`?
